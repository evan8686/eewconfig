项目初衷

一个被系统"静默"的缺口

大陆的地震预警系统尚未接入台湾地区中央气象署（CWA）的预警。而受台湾地震影响明显的福建、浙江地区，常常有明显震感，却得不到任何预警。

2025 年 12 月 27 日 23:05，台湾宜兰外海发生 7.0 级强震。福州因盆地效应震感加剧，经历了持续数分钟的摇晃，华东、华南多省皆有感。然而福建预警全程静默——直到震感过去数分钟后（23:11），才收到地震正式报。

痛点成因

大陆与台湾地区的地震监测网未实现互联，且大陆系统暂无接入 CWA 开放 API 的计划。

预警失能的技术时间差

台湾本岛测站触发预警时，福建系统仍在空等地震波跨海抵达平潭、泉州等基站（约需 30 秒）。等基站完成计算时，地震波已抵达福建大部，被判"失去时效"而弃发。

解决方案

自主开发轻量手机预警 App：直接接入台湾预警数据并打通本地推送，跨过物理监测时间差，在破坏性震感到来前抢占避险窗口。

未来展望

国家级小区广播警报正在部署，但大概率仍不会接入 CWA 数据。对东南沿海用户而言，本应用仍具重要补充价值。

≈ 6 分钟

那场地震中，从"震感结束"到"收到正式报"的静默间隔。本项目的意义，正是把这段时间，换成震前可用的预警。

跨海 30 秒

地震波从台湾本岛抵达福建沿海基站所需的时间——也是官方预警被"判负弃发"的关键窗口。

核心功能

把"及时"和"可靠"放在第一位

每一项设计，都服务于一个目标：在危急时刻，让预警真正送达、真正响起来。

📡

WebSocket 直连

不依赖 Google FCM，通过手机建立长连接直接订阅推送，减少中转环节，避免 FCM 在大陆网络下数小时级延迟。

🔔

常驻监控通知

无预警时通知栏常驻"地震预警监控中"，一旦消失即代表应用被杀后台——让你随时知道它是否还在守护。

🚨

全屏强震警报

达到阈值时，除通知外还触发全屏警报、震动与倒计时，锁屏状态同样可弹出。

🔊

系统闹钟音量播报

采用系统闹钟音量通道，不受媒体静音或响铃模式影响，完全遵循闹钟音量设置，确保第一时间被听见。

🎚️

阈值灵活设置

可调整全屏警报的震级阈值（默认 3 级），也可启用本地预估烈度阈值，按所在地相关性自行取舍。

🗂️

多源订阅 + 最近地震

内置多个预警订阅源（默认开启 CWA），并提供最近地震列表；建议仅勾选与所在地最相关的单一源。

使用说明

四步上手

装好之后，正确配置才能真正发挥预警价值。

⚙️ 快速上手

  1. 选定订阅源 · 进入设置勾选与所在地相关性最高的单一源（默认开启台湾地区中央气象署），避免多源冲突。
  2. 修改阈值 · 调整全屏警报震级阈值（指 EEW 推送震级，非本地实际震级，默认 3），或启用本地预估烈度阈值。
  3. 授予权限 · 开启所有必要通知权限，并按下方"关键配置"完成防杀后台设置。
  4. 运行弹窗测试 · 分别在解锁与锁屏状态模拟触发，确认弹窗、警报音、倒计时、瓦片地图均正常。

📲 通知与警报逻辑

  1. 监控中 · 未收到预警时，通知栏常驻"地震预警监控中"。若消失，代表应用已被系统杀端。
  2. 未达阈值 · 收到 API 推送但未达阈值时，仅弹普通通知。
  3. 达到阈值 · 触发通知 + 全屏警报 + 震动。
  4. 强制警报 · 走系统闹钟音量通道，不受静音/响铃影响。请勿把系统闹钟音量调得过低。
⚠️ 必要关键配置

App 需要后台保活才有意义

请严格按下列方式操作，确保核心预警功能能持续存活并工作。以下以 OPPO ColorOS 16 为例，小米澎湃 OS、vivo OriginOS 等入口略有差异但基本类似。

  • 1 设置 · 通知 · EEW Receiver

    开启"允许通知"并勾选锁屏 / 横幅；打开铃声 / 震动 / 允许打扰（免打扰下仍能响铃震动）；将类别中的"地震预警事件"设为允许通知，"地震预警后台监控"维持默认静默。

  • 2 应用管理 · 权限管理

    "锁屏显示"设为允许；进入"其他权限 → 特殊应用权限"，通过右上角三点"解锁所有授权限制"后，将悬浮窗、后台弹出界面、发送全屏通知均设为允许。

  • 3 多任务界面 · 锁定不清理

    上滑呼出多任务，找到 EEW Receiver，点击三点选择"锁定"，一键清理时不会被杀掉。

  • 4 耗电管理 · 允许后台行为

    进入耗电管理，选择 EEW Receiver，设为"完全允许后台行为"。

  • 5 应用自启动

    在系统"自启动"管理中，允许 EEW Receiver 自启动。

🚨 应用边界与漏报排查

本应用是"防灾避险"工具，而非全球实时监控

同时维持大量 WebSocket 长连接并发，极易被安卓底层识别为异常网络行为或恶意耗电，触发强制断流与杀后台。为确保危急时刻预警的绝对稳定，强烈建议仅勾选与所在地防灾最相关的唯一机构：

福建 · 浙江南部
台湾地区中央气象署 CWA
四川及周边
四川地震局
大陆其他地区
中国地震台网 CENC

本应用不具备独立测定/下发数据的能力，预警完全依赖 Wolfx 开源 API 转发。若仅开启单源、确认后台存活仍遭遇漏报：请先用 WebSocket 工具的 query 指令，查询 Wolfx 服务端当时是否成功下发该报文。未下发属上游数据源原因，请向 Wolfx 咨询；已下发但 App 未响应，才可能属于应用层逻辑异常。
